# Corral

Keyboard-first workspace for running coding agents in terminals. Design: [`docs/design.md`](docs/design.md); engineering: [`docs/engineering.md`](docs/engineering.md).

```sh
mise install && pnpm install
pnpm check          # format, lint, types, Node tests
pnpm test:browser   # component tests in Chromium
pnpm test:e2e       # Electron end to end
```
